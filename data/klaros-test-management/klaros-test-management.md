## Overview

Klaros Test Management is an open-source test case management platform for QA teams. It is designed to be self-hosted and installed via Docker on Windows and Linux.

## Features

- Test case management
- Test cycle organization
- Self-hosted deployment
- Docker-based installation on Windows and Linux

## Pricing

Free and open-source.

## Deployment

Self-hosted; distributed as a Docker setup for Windows and Linux.

## Integrations

Docker for containerized deployment.
