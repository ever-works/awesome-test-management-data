## Overview

Squash TM is an open-source test management platform for QA teams. It supports manual and automated test suites, requirements traceability, Jira integration, and CI integration. It is designed for self-hosted deployment via Docker Compose.

## Features

- Manual and automated test suites
- Requirements traceability
- Jira integration
- CI integration
- Self-hosted deployment via Docker Compose

## Pricing

Free and open-source.

## Deployment

Self-hosted; distributed as Docker Compose.

## Integrations

Jira, CI tools, Docker Compose.
