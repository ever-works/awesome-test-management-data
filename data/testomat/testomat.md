## Overview

Testomat is an AI-powered test management tool designed for modern QA workflows. It manages automated and manual testing in one platform, connecting business analysts, developers, QA engineers, and non-tech stakeholders into a single workflow loop to boost quality and delivery speed with AI agents.

## Features

### AI-Powered Testing
- AI test generation: Creates new tests from Jira user stories, GitHub issues, plain text, or existing tests, reducing manual overhead.
- AI testing agents: Built-in agents that check coverage and release readiness, label flaky and failing tests, write descriptions from code, and convert projects to BDD.
- Flaky test detection: AI analyzes test run history to spot instability patterns like inconsistent results or delays, and auto-tags them as Flaky.
- Context-aware AI assistant: AI suggestions use test cases and requirements as context; follow-up prompts make recommendations more precise.
- AI failure clusterization: Groups automated test failures by pattern so teams fix one root cause instead of triaging dozens of separate errors.

### Manual Testing
- Efficient manual testing: Intelligent Markdown and Gherkin editor with reusable steps and templates. Manage both automated and manual tests.
- Structured test projects: Flexible, scalable UI with multi-level tree folder structure.
- Archive, Versioning & Rollback: Track project history through versioning and revert changes when needed.
- Branching: Work in isolated, trackable branches like Git for parallel testing streams.
- Browser extension for manual testing: Run manual tests in a side panel next to the app under test; capture screenshots, console errors, and failed network requests as evidence.

### Automation Testing
- Seamless test import: Code-first approach with flexible import of test framework code and real-time visibility for automation teams.
- High-level test execution: Select tests using plans, tags, labels, filters, queries, or environments. Run concurrently on CI/CD, manually, from Jira, or combine automated and manual tests.
- Linking tests and notifications: Sync tests by ID or title, link to requirements or Jira, get alerts via Slack, Teams, or email. Failed tests flagged as defects.
- Test automation coverage: Identify coverage gaps and convert manual tests to automated ones with AI-powered code suggestions.

### Analytics & Reporting
- Actionable real-time reports: Instant test progress updates, visualize overall status and readiness, share results with stakeholders.
- Advanced analytics dashboard: Track KPIs and metrics for stakeholders and management.
- AI-assisted reports: AI-driven summaries of test statuses, trends, and defects; highlight issues and group failures to identify root causes.
- Public reports & read-only option: Share test execution results with external stakeholders without requiring a login.

### Integrations
- Live sync with CI/CD: Two-way integration with CI/CD pipelines for automated test execution, real-time result and metric capture.
- Advanced Jira plugin: Bi-directional sync between test cases, test runs, and user stories or epics.
- Multiple test frameworks: Native integration with Playwright, Cypress, Cucumber, Jest, PyTest, and many more.
- Collaboration teams: Full connection to issue tracking, task management, and project collaboration tools.

## Execution Workflow

1. **Plan**: Dynamic test planning based on filters, define test strategy goals, design structure, connect tools, define environment.
2. **Design**: Create test cases, import existing test cases, use AI-testing bot, use templates, steps from database.
3. **Execute**: High-level test execution configurations, wide CI/CD integration, run from issue trackers (Jira), run autotests as manual, mixed runs.
4. **Analyze**: Report and analytics dashboard, automation coverage, usage statistics, Jira defect statistics, PDF/XLS report export.
