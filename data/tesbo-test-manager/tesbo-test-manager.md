## Overview

Tesbo Test Manager is an open-source test case management system designed for QA teams. It supports self-hosted deployment, test case organization, test cycle management, and AI-assisted QA workflows without vendor lock-in.

## Features

- Test case management
- Test cycle organization
- Self-hosted deployment
- AI-assisted QA workflow
- Open-source, no vendor lock-in
